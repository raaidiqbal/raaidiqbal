## About me

I'm Raaid, a developer interested in the whole path from a useful idea to a working product. I enjoy building clear interfaces, dependable backend systems, and understanding the networks that connect them.

Right now, I'm building **[Seonsu](https://github.com/raaidiqbal/Seonsu)**, a return-to-sport recovery prototype with a React and TypeScript interface, versioned progression rules, and a Cloudflare D1 backend. [Try the live demo](https://seonsu.iqbalm-963.workers.dev/).
